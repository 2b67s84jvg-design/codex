# Spellbound Sanctuary Concept Repo

This repository hosts foundational design documentation and data prototypes for **Spellbound Sanctuary**, a 2D magical beast caretaker RPG targeting iPhone.

## Contents
- `docs/magical_pet_game_design.md` — high-level game design foundation covering pillars, systems, and feature roadmap.
- `data/beasts.json` — initial roster of 27 magical beasts with elemental affinities, care preferences, and hybrid breeding combinations.

These assets serve as the baseline for future collaborative iterations on systems, art direction, and gameplay prototypes.
